# StoneBlock

2D平面の石の世界に閉じ込められてしまった。ブラウザで遊べる、2Dブロック採掘ゲームです。

## 起動方法

GitHub Pages を有効にするか、リポジトリの `index.html` をブラウザで開いてください。追加ライブラリやビルド手順は不要です。

## 基本操作

- 初期ワールド中央に 5×5 マスの空洞があります。
- 空気に接しているブロックだけを採掘できます。
- **採掘 ON**：ブロックをクリックすると消えて、インベントリに 1 個追加されます。
- **設置 OFF**：インベントリからブロックを選択し、緑色の枠が付いた空気マスをクリックすると設置できます。
- 設置数を指定すると、クリック地点から空洞の境界に沿って最大指定数まで連続配置します。
- インベントリ画面では地層・岩石・金属・宝石のタブで資源を確認できます。
- インベントリを閉じた状態でも、左右の矢印で簡易資源リストを切り替えられます。
