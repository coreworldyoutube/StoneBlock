# StoneBlock

ブラウザで遊べる、2Dブロック採掘ゲームです。

https://coreworldyoutube.github.io/StoneBlock/

**Game version:** `0.3.0-dev`  
**Save format:** `6`

## 起動方法

GitHub Pages、またはローカル HTTP サーバー経由で `index.html` を開いてください。資源・翻訳データを JSON の `fetch` で読み込むため、ファイルを直接開くのではなく HTTP 経由で起動します。

## 基本操作

- ワールドは 300×300 マス。中央に 5×5 マスの空洞があります。
- 空気に接しているブロックを 1 マスずつ採掘できます。
- 採掘 OFF にすると、インベントリから選択したブロックを 1 マスずつ設置できます。
- シードをランダム生成、または数値指定して地形を再生成できます。地形再生成ではインベントリを保持します。
- 「保存データを初期化」はワールドとインベントリを消去し、新しいランダムシードのワールド中央から開始します。言語設定は保持します。
- ワールドとインベントリはブラウザのローカルストレージに自動保存されます。
- スマートフォンではワールド領域をブラウザ標準の縦横スクロールで移動します。表示範囲の外側は 10 ブロック分の余白を含めて描画します。
- 日本語・英語を切り替えられます。

## 収録資源

土、粘土、砂、石、花崗岩、安山岩、玄武岩、閃緑岩、銅鉱石、鉄鉱石、金鉱石、銀鉱石、プラチナ鉱石、ダイヤモンド、ルビー、エメラルド、アメジスト、サファイア、トパーズ、アクアマリン、石炭、泥炭など。

鉄インゴット・銅インゴット・石粉のIDも、既存インベントリとの互換性と将来拡張のため登録を保持しています。現在の採掘専用版には精錬機能がないため、これらの加工品は新規生成されません。

## データ構成

- `data/blocks.json`：資源・鉱石・燃料・加工品の定義。英語名、色、カテゴリ、生成重みを管理します。
- `data/lang/ja.json`：日本語 UI。
- `data/lang/en.json`：英語 UI。

資源を追加するときは `blocks.json`、表示文言を追加するときは両言語の JSON を更新してください。
