# StoneBlock

ブラウザで遊べる、2Dブロック採掘・工業ゲームです。

https://coreworldyoutube.github.io/StoneBlock/

## 起動方法

GitHub Pages を有効にするか、ローカルサーバー経由で `index.html` を開いてください。JSON データを `fetch` で読み込むため、ファイルを直接開くのではなく HTTP 経由での起動を推奨します。

## 基本操作

- 初期ワールド中央に 5×5 マスの空洞があります。
- 空気に接しているブロックだけを採掘できます。
- 採掘 ON：ブロックをクリックすると 1 マスだけ採掘して回収します。
- 採掘 OFF：インベントリから選択したブロックを 1 マスずつ配置します。
- シード値はランダム生成、または数値指定ができます。
- ワールドとインベントリはブラウザのローカルストレージに自動保存されます。

## 工業・輸送

- 「コンベアを作る」を選び、空気マスをクリックしてベルトを配置します。
- 方向を選んでから配置すると、その向きにアイテムを運びます。
- コンベア 1 マスには左右 2 レーン、それぞれ 4 スロット、合計 8 スロットがあります。
- 「配る」を ON にしてコンベアをクリックすると、選択中のインベントリアイテムをベルトに投入します。
- コンベアを連結するとアイテムが次のベルトへ進みます。
- かまどをベルトの進行先に配置すると、石炭・泥炭を燃料にして鉄鉱石・銅鉱石を精錬し、インゴットをインベントリへ送ります。

## データ構成

- `data/blocks.json`：採掘ブロック、鉱石、燃料、加工品の登録。
- `data/machines.json`：コンベア・かまどなど機械の定義。
- `data/lang/ja.json`：日本語 UI。
- `data/lang/en.json`：英語 UI。

ブロックや翻訳を追加するときは、対応する JSON に登録してください。
